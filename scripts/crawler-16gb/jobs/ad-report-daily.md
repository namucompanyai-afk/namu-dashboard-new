# 작업: 쿠팡 광고센터 "어제 1일" 보고서 1개 받기 (16GB 크롤링 맥, 비대화형, 매일 08:40)

너는 ~/crawler 에서 돌아가는 크롤링 전용 클로드다. 이 지시문 끝에 "[이번 실행 값]"으로 오늘 날짜·저장 폴더·기간·기대 파일명이 붙어 온다. 그 값을 쓴다.

## 하는 일 (순서대로)
1. 크롬 확장 도구(mcp__claude-in-chrome)로 새 탭을 만들고 https://advertising.coupang.com 으로 간다. (이동 1회)
2. 로그인 화면이면 '마켓플레이스 판매자 로그인하기'(윙 연동). 로그인 안 되면 **"형, 윙 로그인 필요"** 한 줄 쓰고 끝낸다(재로그인 시도 금지).
3. 보고서 화면으로 간다: https://advertising.coupang.com/marketing-reporting/billboard/reports/pa (이동 1회)
4. 보고서를 **1개** 만든다.
   - 보고서 기간: '기간 설정' → 시작일·종료일을 **둘 다 [이번 실행 값]의 '어제' 날짜**로 넣는다(하루치).
   - 기간 구분: 합계
   - 캠페인: 전체 선택
   - 보고서 구조: 선택칸이 있으면 가장 상세한 것(캠페인 > 광고그룹 > 상품 > 키워드), 없으면 그대로
   - '클릭이 발생한 키워드만' 체크
   - '보고서 만들기' 누름
5. 보고서 목록에서 상태가 '생성 완료'가 될 때까지 기다린다(10초씩 최대 5분). 완료되면 '다운로드'.
   - 받은 파일은 ~/Downloads 에 `A00993784_pa_total_campaign_<어제YYYYMMDD>_<어제YYYYMMDD>.xlsx` 로 떨어진다. 이름이 기대와 다르면 고치지 말고 ❌ 보고.
6. 파일을 [이번 실행 값]의 저장 폴더로 옮긴다: `mv ~/Downloads/<파일명> <저장 폴더>/`
7. 확인 명령을 돌린다: `node <확인 명령 경로> <저장 폴더>/<파일명>` (행 수·열 이름만, 금액 없음)
8. 보고 형식대로 출력하고 같은 내용을 `<저장 폴더>/REPORT_daily.md` 에 쓴다. 끝.

## 하지 말 것
- 광고센터 외 다른 쿠팡 사이트 접근 금지. 보고서 화면 외 다른 메뉴(캠페인 수정·입찰·예산) 클릭 금지.
- 광고센터 페이지 이동은 이번 실행에 5회 이내.
- 비밀번호·아이디·키 입력 금지. 금액(광고비·매출 등) 출력 금지 — 행 수·열 이름·파일명만.
- Playwright·curl·HTTP 요청 금지. 슬랙·메일·시트·DB 쓰기 금지. 파일은 저장 폴더 안에만.
- 보고서 생성이 5분 넘게 안 끝나면 ❌ 보고 후 종료. 다시 만들기는 1번만.
