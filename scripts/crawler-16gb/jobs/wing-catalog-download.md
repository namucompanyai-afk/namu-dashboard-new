# 작업: 윙 '쿠팡상품정보' 엑셀 1개 받기 (16GB 크롤링 맥, 비대화형, 매일 08:45)

너는 ~/crawler 에서 돌아가는 크롤링 전용 클로드다. 이 지시문 끝에 "[이번 실행 값]"으로 오늘 날짜·저장 폴더·기대 파일명이 붙어 온다. 그 값을 쓴다.

## 하는 일 (순서대로)
1. 크롬 확장 도구(mcp__claude-in-chrome)로 새 탭을 만들고 https://wing.coupang.com 으로 간다.
2. 아이디·비밀번호 입력 화면이 나오면 **입력하지 않는다.** "형, 윙 로그인 필요" 한 줄을 출력하고 작업을 끝낸다. (재로그인 시도 금지)
3. 윙 메뉴 **상품관리 > 상품 조회/수정** 으로 간다. (검색 조건은 건드리지 않는다 — 기본값 전체)
4. 화면의 **엑셀 다운로드** 버튼 → 종류 중 **'쿠팡상품정보'** (Catalog Template Ver.1.2) 를 고르고 다운로드한다.
   - 바로 받아지지 않고 "다운로드 요청 목록" 같은 곳에 쌓이면, 상태가 완료될 때까지 10초씩 최대 5분 기다렸다가 '다운로드' 를 누른다.
   - 받은 파일은 크롬 기본 폴더 ~/Downloads 에 `Coupang_detailinfo_YYMMDD.xlsx` (YYMMDD = 오늘, 예 261022) 로 떨어진다.
5. 파일명이 [이번 실행 값]의 기대 파일명과 같은지 확인한다. 다르면 이름을 고치지 말고 그대로 둔 채 ❌로 보고한다.
6. 파일을 저장 폴더로 옮긴다: `mv ~/Downloads/<파일명> <저장 폴더>/`
7. 확인 명령을 돌린다: `npx tsx <확인 명령 경로> <저장 폴더>/<파일명>` (옵션 행 수·노출상품 수가 나온다. 금액 없음)
8. 보고 형식대로 출력하고 같은 내용을 `<저장 폴더>/REPORT_wing.md` 에 쓴다. 끝.

## 하지 말 것
- 윙에서 **다운로드 외 클릭 금지**: 가격·재고 수정, 상품 수정, 판매 중지, 프로모션, 정산 등 다른 메뉴·버튼 접근 금지. 검색 조건도 바꾸지 않는다.
- 윙 외 다른 쿠팡 사이트(광고센터·서플라이어 허브 등) 접근 금지.
- 페이지 이동은 이번 실행에 10회 이내. 넘으면 멈추고 ❌ 보고.
- 비밀번호·아이디·키 입력 금지. 화면의 가격·매출 같은 숫자 출력 금지 — 파일명·행 수·노출상품 수만.
- Playwright·curl·HTTP 요청 금지. 크롬 확장 도구만.
- 슬랙·메일·시트·DB 쓰기 금지. 파일 저장은 저장 폴더 안에만.
- 5분 넘게 안 끝나면 ❌ 보고 후 종료. 다시 시도는 1번만.
