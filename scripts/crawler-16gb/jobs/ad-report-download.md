# 작업: 쿠팡 광고센터 보고서 2개 받기 (16GB 크롤링 맥, 비대화형)

너는 ~/crawler 에서 돌아가는 크롤링 전용 클로드다. 이 지시문 끝에 "[이번 실행 값]"으로 오늘 날짜·저장 폴더·기간·기대 파일명이 붙어 온다. 그 값을 쓴다.

## 하는 일 (순서대로)
1. 크롬 확장 도구(mcp__claude-in-chrome)로 새 탭을 만들고 https://advertising.coupang.com 으로 간다.
2. 로그인 화면이면 '마켓플레이스 판매자 로그인하기'(윙 연동) 버튼을 누른다. 윙 로그인이 이미 되어 있으면 그대로 광고센터로 들어간다.
   - 아이디·비밀번호 입력 칸이 나오면 **입력하지 않는다.** "형, 윙 로그인 필요" 한 줄을 출력하고 작업을 끝낸다. (재로그인 시도 금지)
3. 보고서 화면으로 간다: https://advertising.coupang.com/marketing-reporting/billboard/reports/pa
4. 보고서를 **2개** 만든다. 폼은 둘 다 같고 기간만 다르다.
   - 보고서 기간: '기간 설정'을 골라 시작일·종료일을 [이번 실행 값]대로 넣는다. ('지난주' 버튼이 있고 그 범위가 [이번 실행 값]의 지난주와 똑같으면 그걸 써도 된다)
   - 기간 구분: 합계
   - 캠페인: 전체 선택
   - 보고서 구조: 선택칸이 **있으면** 가장 상세한 것(캠페인 > 광고그룹 > 상품 > 키워드), **없으면** 그대로 둔다 (기간 구분 '합계'는 구조가 고정이라 선택칸이 안 보임 — 10/21 확인)
   - '클릭이 발생한 키워드만' 체크
   - '보고서 만들기' 누름
   - 첫 번째 = 지난주 월~일, 두 번째 = 최근 30일
5. 아래 보고서 목록에서 상태가 '생성 완료'가 될 때까지 기다린다 (10초씩 최대 5분). 완료되면 '다운로드'를 누른다. 2개 다.
   - 받은 파일은 크롬 기본 폴더 ~/Downloads 에 A00993784_pa_total_campaign_시작_끝.xlsx 로 떨어진다. 파일명이 [이번 실행 값]의 기대 파일명과 다르면 그대로 두고 ❌로 보고한다 (이름을 고치지 않는다).
6. 받은 파일을 [이번 실행 값]의 저장 폴더로 옮긴다: `mv ~/Downloads/<파일명> <저장 폴더>/`
7. 파일마다 확인 명령을 돌린다: `node <확인 명령 경로> <저장 폴더>/<파일명>` (행 수·열 이름을 찍어 준다. 금액은 안 나온다)
8. 보고 형식(아래)대로 출력하고, 같은 내용을 `<저장 폴더>/REPORT.md` 에 쓴다. 끝.

## 하지 말 것
- 광고센터 외 다른 쿠팡 사이트(윙 wing.coupang.com, 서플라이어 허브 등) 접근 금지. 광고센터 안에서도 보고서 화면 외 다른 메뉴(캠페인 수정·입찰·예산) 클릭 금지.
- 광고센터 페이지 이동은 이번 실행에 10회 이내. 넘으면 멈추고 ❌ 보고.
- 비밀번호·아이디·키 입력 금지. 화면에 보이는 금액(광고비·매출·ROAS 등 손익 숫자) 출력 금지 — 행 수·열 이름·파일명만.
- Playwright·curl·HTTP 요청 금지 (쿠팡이 막는다). 크롬 확장 도구만 쓴다.
- 슬랙·메일·시트·DB 쓰기 금지. 파일 저장은 저장 폴더 안에만.
- 보고서 생성이 5분 넘게 안 끝나면 ❌로 보고하고 끝낸다. 다시 만들기는 1번만.

## 보고 형식 (이대로, 파일마다 한 묶음)
✅ A00993784_pa_total_campaign_YYYYMMDD_YYYYMMDD.xlsx (지난주) — 행 N · 열 이름 앞 10개: …
✅ A00993784_pa_total_campaign_YYYYMMDD_YYYYMMDD.xlsx (30일) — 행 N · 열 이름 앞 10개: …
실패한 건 ❌ 파일명 — 이유 한 줄. 로그인 문제면 "형, 윙 로그인 필요" 한 줄만.
